## 复合指标 \(s\)

对每日收益做 63 个交易日滚动 Pearson 相关，`min_periods=63`，然后

\[
s_t = -\mathrm{corr}_t(\mathrm{SPY},\mathrm{TLT}) - \mathrm{corr}_t(\mathrm{SPY},\mathrm{DXY}) + \mathrm{corr}_t(\mathrm{SPY},\mathrm{GLD}) + \mathrm{corr}_t(\mathrm{TLT},\mathrm{DXY})
\]

- 理论范围 \([-4, 4]\)。
- \(s\) 较高，对应 SPY–TLT、SPY–DXY 更负，且 SPY–GLD、TLT–DXY 更正。
- 相关有符号对称性：一对资产的相关下降，既可能是“股票跌、对手涨”，也可能方向对调，不能单独把 \(s\) 的水平或变化读成单一的 risk-off。黄金也不是稳定对冲。63 日窗口在某根大日子滚出时，相关可能跳变。

## 速度 \(Z\)

\[
\Delta s_t = s_t - s_{t-21}
\]

\(\mu_t\)、\(\sigma_t\) 只用 \(\Delta s\) 在 \(t\) 之前的 180 个交易日（实现上为 `dx.shift(1).rolling(180, min_periods=180)`），样本标准差 `ddof=1`：

\[
Z_t = \frac{\Delta s_t - \mu_t}{\sigma_t}
\]

\(Z_t\) 本身是因果的，不含当天之后的样本。图上那根不变的 1.25 虚线只是固定阈值，不是全样本拟合，也不构成前视。

## 门控

- \(\mathrm{SMA}30_t\)：SPY 收盘价最近 30 个交易日的简单均值，**包含当日**。
- 仅当 \(\mathrm{SPY}_t < \mathrm{SMA}30_t\)（严格小于；相等不算低于）时，门控打开。

## 交易规则

1. 若 \(Z_t > 1.25\) **并且** \(\mathrm{SPY}_t < \mathrm{SMA}30_t\)，当日收盘信号为空仓；否则满仓 SPY。
2. 信号在 \(t\) 日收盘确认，**次日** \(t+1\) 才生效。\(t\) 日当天的收益，仍按前一日已经生效的仓位计算。例如某日收跌且信号第一次发出，当日收益已经计入，空仓从下一交易日开始。
3. 空仓时持有 BIL 的总回报，不是零利息现金。
4. 交易成本按 0 处理（VY 已声明暂时不考虑 trading cost）。
5. \(Z\) 或 30 日均线尚未形成、信号为缺失时，该日规则收益记为缺失，与现有实现一致。

伪代码（与 `/workspace/cross-asset-corr-4asset-check/plot_gate_z_grid.py` 一致）：

```text
dx = s - s.shift(21)
mu = dx.shift(1).rolling(180, min_periods=180).mean()
sd = dx.shift(1).rolling(180, min_periods=180).std(ddof=1)
z  = (dx - mu) / sd
sma30 = spy_close.rolling(30, min_periods=30).mean()
signal_cash = (z > 1.25) & (spy_close < sma30)    # 在 z 缺失处保持缺失
applied_cash = signal_cash.shift(1)
ret = bil_ret if applied_cash else spy_ret
```

## 回测约定

- 正式全样本：净值在 **2007-05-31** 设为 1（受 BIL 起始日约束），第一个收益日是 2007-06-01，到四资产共同样本末端为止。
- 从某一日历日开始的切片（例如 2017 初、2020 初、2025 初）：净值在该日之前最近一个交易日设为 1，从下一交易日起计收益；**可以用切片之前的历史**计算 63 日相关、21 日变化、180 日 Z 和 30 日均线。
- 区间收益：\(P_{\mathrm{end}} / P_{\mathrm{start}} - 1\)，不含起点当日收益；同时报告区间内最大回撤。期末收益单独看会掩盖途中低点。
- 年化交易日 252；波动与 Sharpe 用样本标准差 `ddof=1`；Sharpe 的无风险利率为 0。
- 不要把不同篮子或不同起始日的净值，当作同一样本直接比较。
