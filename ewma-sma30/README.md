# EWMA 符号协方差 + SMA30（当前实盘规则，未冻结）

这是当前正在使用的 SPY 满仓 / 空仓 EWMA 信号。它和仓库根目录那套已经冻结的 Pearson 规则（Z>1.25 + SPY 30 日均线）是两套独立实现：

- 本目录**没有冻结**。它不是预注册检验，也不是样本外验证过的最优参数。
- 它**不是**冻结规则的修改、升级或替代。不要拿这里的结果去改冻结规则的篮子、公式、窗口或阈值。
- 本包只计算信号和回测，**不会下单，也不会改仓**。

下面这组参数就是当前实盘规则。命令行不能改它们。这里没有网格搜索，也没有那些试过但没有当作实盘规则的变体（SMA10、λ=0.90、5 日跌幅 −0.75、最短持有 5 日）。

## 数据

- 篮子：SPY、TLT、GLD、DXY。DXY 是 ICE 美元指数，yfinance 代码 `DX-Y.NYB`，不是 UUP。
- 空仓持有 BIL 总回报，满仓持有 SPY。交易成本按 0。
- 价格用复权收盘：yfinance `period=max`、`interval=1d`、`auto_adjust=True`。
- 四资产按日期内连接。某一天缺任何一只，就丢掉这一天，不向前填充。
- 复合指标用共同交易日上的对数收益。相邻两个共同交易日之间如果隔了一个缺口，这一步对数收益跨过该缺口。
- SPY 和 BIL 的策略收益先在各自交易日历上做简单收益，再对齐到四资产共同交易日。只在 SPY 开市、不在共同样本里的那一天，不会单独成为一条策略收益，但它的收盘价是下一天 SPY 收益的分母。
- 30 日均线同样在 SPY 自己的交易日上计算（含当日），再对齐到共同交易日。SPY 单独开市的那一天仍进入均线。
- 新下载只写到 `--write-cache-dir`（默认 `./cache`）。程序拒绝写入已知的官方研究缓存，也拒绝写入冻结包目录。

## 复合指标

记 \(r_t\) 为四资产对数收益列向量。RiskMetrics EWMA 协方差，λ = 0.94，收益不减均值：

```text
Σ_0 = r_0 r_0'
Σ_t = λ Σ_{t-1} + (1-λ) r_t r_t'
```

前 60 个交易日的协方差不进入后面的 z。这 60 天只是从输出里拿掉，递归不重置，第一天被保留的 Σ 已经包含它们。

对 SPY–TLT、SPY–DXY、SPY–GLD、TLT–DXY 四对协方差做因果滚动 z。窗口 504 个交易日，`min_periods=252`。均值和标准差只用 t 之前的值（先 rolling，再 `shift(1)`），样本标准差 `ddof=1`，标准差低于 `1e-12` 时截到 `1e-12`：

```text
z_t = (c_t - μ_t) / σ_t
S_t = -z_t(SPY,TLT) - z_t(SPY,DXY) + z_t(SPY,GLD) + z_t(TLT,DXY)
```

S 的 252 日滚动百分位，`min_periods=126`，窗口内 `rank(pct=True)`，并列取平均秩。百分位含当日 S，不含当日之后的 S。信号在 t 日收盘形成、t+1 才执行，所以用到当日收盘不是用了未来数据。

热身之后的序列再丢掉前 504 行（`iloc[504:]`）才对外公布。起点那一天的 z，用的是它之前刚好 504 个协方差，基线是满的。百分位在这次截断之前就算完，所以第一天公布的百分位仍然看得到更早的 S。

## 交易规则

实盘参数：SMA30，λ=0.94，drop=−0.70。t 日收盘信号在 t+1 生效。

均线是 SPY 最近 30 个自身交易日收盘的简单均值，含当日，满 30 天才形成。

- 严格低于均线：收盘价 < SMA30。相等不算低于。
- 严格高于均线：收盘价 > SMA30。相等不算高于。

### 规则 1

- 百分位 > 0.9 时，规则 1 处于风险关闭；百分位 ≤ 0.9 时退出。百分位缺失则当天状态缺失，闩锁不更新。
- 在一次风险关闭里，只要出现过收盘价严格低于 SMA30，规则 1 就保持空仓，直到这次风险关闭回到 0。价格重新站上均线，本身不能解除规则 1。
- 百分位已经大于 0.9、但还没有跌破均线时，规则 1 的收盘信号仍是满仓。
- 风险关闭回到 0 的当天闩锁清零。下一次要重新跌破均线，才会再次因规则 1 空仓。

### 规则 2

- `high5` 是含当日的 5 日百分位最高值，`min_periods=5`。`drop5 = pct - high5`。
- 已经空仓时，先检查退出，再检查同一天要不要重新进入。退出和入场在同一天都成立时，收盘信号仍是空仓。
- 退出：前一日百分位 < 0.25 且当日百分位 ≥ 0.25，或者收盘价严格高于 SMA30。
- 进入：`drop5 ≤ −0.70`，并且收盘价严格低于 SMA30。
- 百分位或 drop5 缺失的日子不更新持仓状态，当天信号记为缺失。

### 合并与执行

- 收盘 `signal_cash` = 规则 1 或规则 2。百分位缺失时，合并信号缺失。
- 次日持仓是前一日的收盘信号。空仓拿 BIL，否则拿 SPY。
- 生效仓位还没形成时，当天规则收益记为缺失。信号翻转当天仍按翻转前的仓位计算收益。

## 回测约定

算法和冻结包相同，评价的是本规则自己的信号：

- 净值在 2007-05-31 设为 1。第一笔计入的收益是下一交易日（正常样本里是 2007-06-01），一直算到本次数据里四资产共同样本的最后一天。
- 若公布序列在 2007-05-31 之后才开始，净值改在第一个公布日设为 1，从下一交易日起计收益。一次从 GLD 上市附近开始的全历史下载，公布序列会早于 2007-05-31。
- 年化按 252 个交易日。波动和 Sharpe 用样本标准差 `ddof=1`。Sharpe 的无风险利率是 0。
- 区间收益是 `P_end / P_start − 1`，不含起点当日收益。
- 最大回撤、空仓占比、仓位切换次数和冻结包的回测助手用同一定义。第一个计入日相对“没有前一日仓位”会计为一次切换。
- 结果是 0 成本的现算数字，不是样本外验证。本说明不登记一张正式业绩表。缓存会随复权修正变化，同一段历史以后重下，数值也可能变。

未收盘的 K 线不参与计算。美东时间 16:15（含）之后，当天视为已经收盘；周末或 16:15 之前，最后允许的交易日是上一工作日。不带时区的时间按美东理解。

`signal` 要求最新一根 SPY K 线同时有 TLT、GLD、DXY。缺任何一只就报错，不会悄悄改用更早的共同交易日。`backtest` 则算到共同样本的最后一天，这个终点可以早于最新的 SPY 交易日。

## 安装与运行

在本目录单独安装。仓库根目录的 `pip install -e .` 仍然只安装冻结规则，不会提供 `ewma-sma30` 这条命令。

```bash
cd ewma-sma30
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

下载并给出最近一个已收盘信号（次日生效）：

```bash
ewma-sma30 --download signal
```

缓存文件名为 `SPY_max.csv`、`TLT_max.csv`、`GLD_max.csv`、`DXY_max.csv`、`BIL_max.csv`，列里要有日期和 `Close`：

```bash
ewma-sma30 --cache-dir /path/to/cache signal
ewma-sma30 --cache-dir /path/to/cache backtest
```

`backtest` 默认从 2007-05-31 算到最后一根已收盘的共同样本，并和买入持有 SPY 对照。`--start`、`--end` 只改变评价窗口，不改变信号公式。`--out some.csv` 把日序列写到你指定的路径。`cache/`、`output/`、csv 和 png 都在本目录的 `.gitignore` 里，不要提交。

也可以：

```bash
python scripts/run_ewma.py --cache-dir /path/to/cache signal
```
